# Quack releases

Installers and update manifests for Quack, the two-way Roblox Studio <-> disk sync.
The Quack app checks `latest.json` here for new versions and installs them itself.

Quack is licensed under the GPL-3.0 (it started as a fork of
[Azul](https://github.com/Ransomwave/azul)). Every release carries the full source of
that version as `quack-<version>-source.zip`, next to its installer.
